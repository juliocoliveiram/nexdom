# Desafio FullStack
Construir uma aplicação RESTful para controle de estoque com no mínimo duas 
entidades, como por exemplo: Produto e Movimento Estoque.

# Uso de Tecnologias
## Tecnologia BackEnd
* Java Spring Boot
  
## Tecnologias FrontEnd:
* React

### Observações
Neste projeto é possível efetuar entrada e saída de produtos no estoque, validando o saldo na saída de cada produto e se existe quantidade suficiente. Caso a quantidade de saída não seja suficiente, é retornada uma mensagem informativa. 
Também é possível efetuar a consulta dos produtos por tipo, com sua respectiva quantidade de saída e quantidade disponível. Consultas de lucro por produto, exibindo a quantidade total de saída, e total do lucro
